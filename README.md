# Liquid Lyrics

Liquid Lyrics is a modern Spicetify lyrics extension.

It brings a smooth, theme-matching lyrics experience to Spotify with word-by-word synced
lyrics, fullscreen lyrics, romanization support, an optional media player and an expandable
sidebar lyrics card.

It was built alongside **Glowify** and **Liquify** and still fits those two best, but it is no
longer made just for them. Under any other theme it now picks up that theme's look instead.
And if you want something else entirely, the settings menu lets you build your own.

## Features

### Smooth Word-by-Word Lyrics

Liquid Lyrics supports smooth synced lyrics with fluid word-by-word animations.

For lyrics formats that do not support word-by-word syncing, it can also display classic
block-style lyrics. If you prefer less movement, there are two calmer display modes.

Scrolling runs on Lenis, so the lyrics glide from line to line instead of jumping, and the
mouse wheel is smoothed along with them. You can turn that off or change how long the glide
takes.

While a song's lyrics are still being searched, the panel fills with placeholder lines rather
than sitting empty.

### Romanization Support

Romanized lyrics can be toggled on or off.

This is useful for songs in languages such as Japanese, Korean, Chinese and other non-Latin
scripts.

For Japanese songs there is a **Furigana** mode as well. Instead of replacing the lyrics with
latin letters, it keeps the original text and puts the reading above it, so you can still read
along if you know some Japanese. The button cycles through off, Romaji and Furigana, and
Furigana only shows up on songs that actually have Japanese in them.

### Settings Menu

Liquid Lyrics has a full settings menu. Open it from the gear in the top right of the lyrics
page, or from the Spicetify profile menu under **Liquid Lyrics Settings**.

Almost everything can be changed there: buttons, the interface, the lyrics page, fullscreen
behaviour, backgrounds, the media player, the sidebar card and the lyrics themselves. There is
a search box, jump buttons for each section, and a reset if you go too far. Every change
applies right away.

The first time you open the lyrics page, a short tour points out where the settings are and
the two ways to reach them.

### Backgrounds

The background behind the lyrics can be a plain color, a picture, the animated cover-art
blobs, or **Kawarp**, a flowing artwork effect that is the default.

Kawarp bends and drifts the album art in real time on your graphics card, with its own warp
intensity and motion speed. If your setup cannot run it, it falls back to the animated field
on its own.

The picture can come from the album art, a link, or a file on your computer, and there are
steppers for blur, scale, opacity, brightness, contrast, saturation and motion. You can also
let the background fill Spotify's whole right sidebar.

### Fullscreen Lyrics Mode

Liquid Lyrics includes a dedicated fullscreen lyrics view for a more immersive listening
experience, plus a cinema mode that fills the Spotify window without leaving it.

In both, the interface fades away on its own after three seconds of stillness and comes back
the moment you move the mouse. The cursor goes with it, and the delay is adjustable. Each
track detail can fade out separately, so you can keep the song name and drop the album.

Player controls appear in the control pill automatically in fullscreen, so play, pause and
skip stay within reach even when the song card sits far off to one side.

### Optional Media Player

Liquid Lyrics includes an optional media player inside the lyrics view.

There are two layouts to choose from, it can sit on either side and glides across when you
switch, and you decide which track details it shows.

When a song has no lyrics at all, the panel does not have to show a message. It can show the
player enlarged in the middle instead, or the cover art spinning like a record.

### Sidebar Lyrics Card

Spotify once had a sidebar lyrics card and later removed it.

Liquid Lyrics brings this feature back with a modern design. The card can be collapsed,
opened, or expanded into a large view, and its height and minimum height are yours to set.

## Themes

Liquid Lyrics is designed around the style of **Glowify** and **Liquify**: glass effects,
accent colors, rounded corners and smooth animations. Under those two it uses their own
variables directly, so it is part of the theme rather than a guest in it.

Under any other theme it adapts on its own. It looks at Spotify's Now Playing View panels as
that theme has styled them and copies what it finds:

- the shadow those panels use, applied to the lyrics page, the sidebar card and the settings
  menu
- a border instead, if the theme outlines its panels rather than shadowing them. It gets read
  off and turned into an edge of the same width and color
- the blur behind the glass, so the lyrics panel frosts the same way the theme's own panels do
- the panel fill and corner rounding, which the sidebar card takes over as well, since it sits
  right among those panels
- if the theme draws neither a shadow nor a border, a thin line in your accent color, so the
  panels never dissolve into the background

Accent colors come from the album art and follow the music, so there is always one even under
a theme that sets none.

Some details may still not match perfectly outside of Glowify and Liquify. If something looks
off, most of it can be changed in the settings.

## Installation

### Marketplace Installation

Once Liquid Lyrics is available in the Spicetify Marketplace, you will be able to install it
directly from there.

1. Open Spotify
2. Open the Spicetify Marketplace
3. Search for Liquid Lyrics
4. Click install
5. Reload Spotify

### Manual Installation

Download the latest `liquid-lyrics.js` file and place it inside your Spicetify extensions
folder.

**Windows:**

```
%appdata%\spicetify\Extensions\
```

**Linux / macOS:**

```
~/.config/spicetify/Extensions/
```

Then enable the extension:

```bash
spicetify config extensions liquid-lyrics.js
spicetify apply
```

## Compatibility

Liquid Lyrics is designed for the current Spotify and Spicetify UI.

Because Spotify updates its desktop client frequently, some parts of the extension may break
after Spotify updates. Updates and fixes will be released when needed.
